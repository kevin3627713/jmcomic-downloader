# 按章节阅读和导出 PDF

本分支基于 `codex/linux-ios-xtool`，保留 Linux iOS 构建脚本。

## 使用

在书库点 PDF 图标的“阅读 / 导出”，或在章节页点“阅读 PDF”/“导出 PDF”，打开统一面板：

1. 选择“阅读”或“导出”。阅读会先生成所需 PDF，再打开系统阅读器。
2. 选择“整本”或“选择章节”。整本要求当前章节列表全部下载完成；未下载的章节不可勾选。
3. 选择章节支持搜索、全选已下载和清空，搜索不会丢失其他已选章节。全选始终选择全部已下载章节，而不只是搜索结果。
4. 多章可“合并为一个 PDF”连续阅读，或“每章一个 PDF”，在 iOS 系统预览中切换。单章只生成一个 PDF。
5. 底部固定显示范围、文件数和确认按钮。导出完成后可阅读，或在 iOS 分享/存储到文件；桌面端交给系统打开。

PDF 选择独立于下载选择，不会误操作下载任务。长标题换行、章节列表滚动、操作按钮保留触控尺寸。生成期间阻止重复提交；关闭、重新进入会重新核对下载状态。阅读器打开失败后可重试打开已生成文件，不必再次生成。

## 文件行为

- 整本只留下一个整本 PDF。
- 单章或分章只生成指定章节 PDF。
- 多章合并只留下所选章节的合并 PDF，不额外保留中间分章 PDF。
- 始终按漫画原章节顺序排列，重复 ID 去重，不接受其他漫画或未完成下载的章节。
- 新的分章/选章合并 PDF 都保存在漫画导出目录的 `pdf/` 中，现有文件计数和删除 PDF 功能可识别。
- 以前已经导出的 PDF 不自动删除。相同范围再次生成会原子替换对应文件；失败不会把已有成功 PDF 覆盖为空文件。
- 读取按需生成的 PDF 仍需要原始下载图片。本次不是脱离图片的历史 PDF 文件浏览器。

## 验证

- 前端类型检查、生产构建与手写修改文件 ESLint 通过。全仓 `eslint src` 仍有源分支既有的 39 项问题（含生成绑定），没有把局部检查当作全仓 lint 通过。

- `rustc --test src-tauri/src/pdf_selection.rs -o /tmp/pdf-selection-tests && /tmp/pdf-selection-tests`：5 项后端选择规则回归。
- `export.rs` 包含 PDF 生成、合并、页面顺序、锁及原子写入测试；本次在独立宿主测试框架中运行生产辅助函数，避开宿主 GTK 依赖，不等于全应用 `cargo test`。
- 本次还通过 6 项隔离 Vue 组件交互测试：单章阅读、分章导出、整本、打开失败重试、重复点击、关闭后的过期响应。

- Linux 构建与静态 IPA 校验不代替真机运行。真实浏览器视觉检查受当前执行环境限制，未完成；iOS 分享/QuickLook 多文件切换、横竖屏与实际长篇 PDF 的内存表现仍需真机验证。
